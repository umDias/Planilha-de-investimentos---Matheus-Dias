# Planilha-de-investimentos---Matheus-Dias
Segue a planilha para realizar projeções financeiras, onde temos diversos campos que podemos adicionar informações e projetar quanto podemos ganhar com nosso dinheiro, a planilha ainda vem com dicas de distribuição de investimento a depender do perfil do cliente.
Podemos dentro da planilha colocar aproximadamente a porcentagem que o nosso dinheiro rende por mês, assim como o quanto ganhamos, a porcentagem de salario que pretendemos investir e quantos anos pretendemos seguir esse modelo, a planilha é bem completa e é capaz de gerar projeções matematicamente corretas.
O VF funciona como colocando a porcentagem de rendimento mensal, os anos que foram investidos *12, o aporte mensal e ainda um aporte inicial que é comum quando começamos a investir, fazendo a projeção matemática de quanto essa valor será no futuro com pagamentos constantes e periodicos.
O PROCV serve para buscar uma informação específica em uma tabela e trazer um dado correspondente que está na mesma linha, no nosso caso usamos ele para buscar o perfil em que o cliente é, e realizar as recomendações de investimento para o mesmo, usando de referencia os FII(Fundos imobiliários).
Além disso foram inseridos diversos intervalos nomeados dentro do Excel para ajudar o cliente a compreender o uso das fórmulas que são usadas para os cálculos. 
Já em relação aos percentuais de cada perfil eu pedi ajuda do CHATGPT, como eu não tenho muito conhecimento em fundos imobiliários ele me recomendou as porcentagens baseadas em pesquisas.
Eu realizei diversas mudanças visuais referente ao sistema do expert, além disso adicionei uma aba de investimento inicial, visto que isso é uma das praticas comuns de quem investe ou já investiu anteriormente, além disso troquei a aba de configuração pela aba de informações onde é possível o cliente alterar a porcentagem que ele deseja investir do próprio salario ao invés de ser algo pré-estabelecido.
Todos os testes foram realizados garantindo que a planilha está funcionando devidamente.
